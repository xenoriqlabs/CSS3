CSS Cascade

1. Cascade

The CSS cascade determines which declaration should be applied when multiple CSS rules target the same element.

The cascade considers factors such as importance, layers, specificity, and source order.

2. Source Order

Two selectors have the same specificity.

First rule:

color: blue;

Later rule:

color: red;

Result: Red

The later declaration wins because specificity is equal.

3. Specificity

This paragraph is targeted by both a class and an ID.

Class specificity: 0-0-1-0

ID specificity: 0-1-0-0

The ID selector wins.

4. Importance

This text uses !important.

color: orange !important;

The !important declaration can override normal declarations even when the normal selector has higher specificity.

5. Specificity + Source Order

ID wins over class and element selectors.

Element: 0-0-0-1

Class: 0-0-1-0

ID: 0-1-0-0

Result: Red

6. Cascade Layers

This paragraph demonstrates cascade layers.

Base layer: Blue

Components layer: Red

The later normal layer has higher priority than the earlier normal layer.

7. Inline Style

Inline styles have high cascade priority among normal author declarations.

style="color: purple;"

8. Source Order Practical Test

The later rule wins when competing rules have equal specificity.

First:

background-color: lightblue;

Later:

background-color: lightgreen;

9. Quick Summary

Cascade: Decides which CSS declaration applies.


Importance: !important changes the priority level.


Layers: Organize CSS and control priority between groups of rules.


Specificity: Determines which selector is stronger.


Source Order: If competing declarations remain tied, the later declaration wins.
