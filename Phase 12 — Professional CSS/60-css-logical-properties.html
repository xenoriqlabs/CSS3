CSS Logical Properties - Xenoriq Labs

1. margin-inline

Xenoriq Labs

This box uses margin-inline.

margin-inline: 40px;

This controls the margin on the inline-start and inline-end sides.

2. padding-inline

Xenoriq Labs

This content has 50px of inline padding.

padding-inline: 50px;

This controls padding in the inline direction.

3. inset-inline

Positioned Element

This element uses inset-inline.

position: absolute;
inset-inline: 30px;

This sets both inline offsets to 30px.

4. block-size

Block Size

This element uses block-size: 200px.


In normal horizontal writing mode, block-size generally corresponds to height.

block-size: 200px;

5. inline-size

Inline Size

This element uses inline-size: 500px.


In normal horizontal writing mode, inline-size generally corresponds to width.

inline-size: 500px;
max-inline-size: 100%;

9. Quick Summary

margin-inline: Controls margin in the inline direction.


padding-inline: Controls padding in the inline direction.


inset-inline: Controls positioned offsets in the inline direction.


inline-size: Controls size in the inline direction.


block-size: Controls size in the block direction.
