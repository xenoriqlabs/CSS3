1. Inherited Properties

Parent Element

This paragraph inherits color, font-family, font-size, and font-weight.

Common inherited properties:


color, font-family, font-size, font-style, font-weight, line-height, text-align

2. Non-Inherited Properties

Parent Element
Child Element

Padding, border, and background are not automatically inherited.

Common non-inherited properties:


margin, padding, border, width, height, background, display, position

3. inherit

Parent Element
Child Element

This child explicitly inherits the parent's color and border.

color: inherit;
border: inherit;

4. initial

Parent Element

This child uses the property's initial value.

color: initial;
font-size: initial;

5. unset

Parent Element

This element uses unset.

For inherited properties:

unset = inherit

For non-inherited properties:

unset = initial

6. revert

Parent Element

This paragraph uses revert.

color: revert;
font-size: revert;

Revert rolls the property back toward the styling from an earlier CSS origin.

7. Keyword Comparison

Parent Element

inherit → Parent's value

initial → Initial value

unset → inherit or initial

revert → Earlier CSS origin

8. Quick Summary

Inherited properties: Automatically pass from parent to child.


Non-inherited properties: Do not automatically pass to children.


inherit: Use the parent's value.


initial: Use the property's initial value.


unset: Acts like inherit or initial depending on the property.


revert: Return toward styling from an earlier CSS origin.
