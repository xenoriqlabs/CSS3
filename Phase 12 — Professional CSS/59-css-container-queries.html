7. Quick Summary

container-type: Defines an element as a query container.


@container: Applies CSS based on the size of a query container.


inline-size: Allows queries based on the container's inline dimension.


container-name: Gives a query container a name.


container: Shorthand for container name and type.


Media Query: Responds mainly to the viewport.


Container Query: Responds to the component's container.
