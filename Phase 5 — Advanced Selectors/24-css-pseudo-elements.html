3. ::first-letter

::first-letter styles the first letter of an element.
This is commonly used for magazine/article-style text.

4. ::first-line

::first-line styles the first line of text inside an element.

CSS allows you to create beautiful websites. You can control colors, fonts, spacing, layouts, animations, and much more. The browser will not preserve the extra spaces and line breaks exactly as you wrote them. HTML normally collapses multiple spaces and line breaks into a single space.

5. ::selection

::selection styles text when the user selects/highlights it with the mouse.

Select this text with your mouse to see the effect.

6. ::placeholder

::placeholder styles the placeholder text inside an input or textarea.
