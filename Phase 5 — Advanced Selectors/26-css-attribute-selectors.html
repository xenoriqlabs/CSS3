CSS Attribute Selector

1. [attribute] — Attribute Exists

Selects every element that has the specified attribute, regardless of its value.

The first two inputs are selected because they have the name attribute.

2. [attribute=value] — Exact Value

Selects elements whose attribute has an exactly matching value.

3. [attribute^=value] — Starts With

The ^= selector targets elements whose attribute value starts with the specified value.

Google GitHub Example

4. [attribute$=value] — Ends With

The $= selector targets elements whose attribute value ends with the specified value.

5. [attribute*=value] — Contains

The *= selector targets elements whose attribute value contains the specified text

6. [attribute~=value] — Contains a Whole Word

The ~= selector selects elements where the attribute value contains the specified whole word, separated by spaces.

7. [attribute|=value] — Exact Value or Starts With value-

The |= selector matches an attribute whose value is either:

  1. Exactly the specified value, or
  2. Starts with the specified value followed by a hyphen -.

It is commonly used with language attributes.
