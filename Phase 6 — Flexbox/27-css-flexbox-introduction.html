CSS Flexbox Introduction

1. Flex Container

A Flex Container is an element that has display: flex;.

Its direct children become Flex Items.

2. Flex Items

Flex Items are the direct children of a Flex Container.

In this example, the three .item elements are Flex Items.

3. Main Axis

The Main Axis is the primary direction in which Flexbox places the flex items.

By default, flex-direction is row, so the Main Axis goes from left to right.

If you change the direction to a column: flex-direction: column;

Now the Main Axis becomes top to bottom

4. Cross Axis

The Cross Axis is the axis that is perpendicular to the Main Axis.

Easy Rule

Main Axis = direction of your flex items

Cross Axis = axis perpendicular to the Main Axis
