CSS Padding

01 - Individual Padding

Padding can be applied separately to the top, right, bottom, and left sides of an element.

02 - Padding Shorthand - 1 Value

When one value is used, the same padding is applied to all four sides.

03 - Padding Shorthand - 2 Values

The first value applies to top and bottom, while the second value applies to left and right.

04 - Padding Shorthand - 3 Values

Three values represent top, left/right, and bottom.

05 - Padding Shorthand - 4 Values

Four values represent top, right, bottom, and left.

06 - Padding vs Margin

Padding creates space inside an element, between the content and border.

Margin creates space outside an element, between the element and other elements.
