CSS Grid Areas

1. grid-template-areas

grid-template-areas allows us to give names to different parts of a grid layout.

Header
Sidebar
Main
Footer

2. Header

Header usually contains the logo, website name, and navigation.

3. Sidebar

Sidebar usually contains menus, links, categories, or additional information.

4. Main

Main contains the primary content of the webpage.

5. Footer

Footer usually contains copyright, contact information, and useful links.
