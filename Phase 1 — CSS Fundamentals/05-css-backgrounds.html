Background in CSS3

Background Color

This is div about background color.

Background Image

Background image in CSS is used to place an image behind the content of an HTML element. You can use the background-image property to add an image, and then control how it appears using properties like background-repeat, background-position, and background-size.

Linear Gradient

A linear gradient in CSS creates a smooth transition between two or more colors along a straight line. You can control the direction of the gradient, such as from left to right, top to bottom, or at a specific angle. It is commonly used for backgrounds, buttons, cards, and other UI elements to create attractive visual effects without using an image. The `linear-gradient()` function is used with the `background` or `background-image` property.

Radial Gradient

A radial gradient in CSS creates a smooth transition between two or more colors that spreads outward from a central point in a circular or elliptical shape. Unlike a linear gradient, which moves in a straight line, a radial gradient starts from the center and gradually changes colors toward the edges. It is created using the `radial-gradient()` function and is commonly used for backgrounds, glowing effects, highlights, and modern UI designs.

Conic Gradient

A conic gradient in CSS creates a smooth color transition around a central point, similar to the hands of a clock moving in a circular direction. Unlike a linear gradient that moves in a straight line or a radial gradient that spreads outward from the center, a conic gradient rotates around the center point. It is created using the `conic-gradient()` function and is commonly used for pie charts, color wheels, loading indicators, borders, and creative backgrounds.
