CSS Box Model

01 - Content

Content is the actual text, image, or other information inside an HTML element.

02 - Padding

Padding creates space between the content and the border of an element.

03 - Border

Border creates a visible boundary around the padding and content of an element.

04 - Margin

Margin creates space outside an element and separates it from other elements.

05 - Content Box

With content-box, the width applies only to the content. Padding and border are added outside the specified width.

Width = 300px + 40px padding + 10px border = 350px

06 - Border Box

With border-box, the specified width includes the content, padding, and border.

Total Width = 300px
