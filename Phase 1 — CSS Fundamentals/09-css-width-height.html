CSS Width - Height

1 - Width Property

The width property defines the width (chaurayi) of an element.

2 - Height Property

The height property defines the height (unchai) of an element.

3 - Min-Width Property

`min-width` sets the minimum allowed width of an element.

4 - Max-Width Property

`max-width` sets the maximum allowed width of an element.

5 - Min-Height Property

`min-height` sets the minimum allowed height of an element.

6 - Max-Height Property

`max-height` sets the maximum allowed height of an element.

07 - Content Box

With content-box, width applies only to the content. Padding and border are added separately.

08 - Border Box

With border-box, width includes content, padding, and border.
