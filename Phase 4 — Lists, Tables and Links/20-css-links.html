CSS Link

1 - :link

If you have never visited the link, it will appear blue. Only applies to unvisited links.

Not visited link

2 - :visited

Used to style a link that the user has already visited.

Already visited link

3 - :hover

Used when you move your mouse over the link.

Mouse over link

4 - :active

Applies while you are clicking/pressing the link.

Currently clicking link
