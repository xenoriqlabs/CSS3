CSS Text

01 - color

The color property is used to set the color of text.

02 - text-align

The text-align property is used to align text horizontally inside an element.

03 - text-align-last

The text-align-last property controls the alignment of the last line of a text block. This example uses justified text with the last line centered.

04 - text-decoration

The text-decoration property is used to add lines to text such as underline, overline, or line-through.

05 - text-transform

The text-transform property controls the capitalization of text.

06 - text-indent

The text-indent property moves the first line of a paragraph inward from the left side. This is useful for creating a traditional paragraph indentation.

07 - letter-spacing

The letter-spacing property controls the amount of space between individual characters.

08 - line-height

The `line-height` property in CSS controls the amount of vertical space between lines of text. It helps make text easier to read by increasing or decreasing the spacing between lines. A larger `line-height` creates more space between lines, while a smaller value makes the lines closer together. It can be used with units such as `px`, `em`, or `rem`, or with a unitless number.

09 - Word Spacing

The word-spacing property controls the amount of space between words in a text.

10 - text-shadow

The text-shadow property adds a shadow effect behind text. You can control its horizontal position, vertical position, blur, and color.
