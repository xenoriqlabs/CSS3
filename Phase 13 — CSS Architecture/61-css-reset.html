CSS Reset & Normalize

1. Browser Defaults

Xenoriq Labs

Browsers provide default styles for HTML elements.

CSS resets help us create a predictable starting point.

Examples of browser defaults include:


  • Heading sizes
  • Paragraph margins
  • List bullets
  • Link colors
  • Button appearance

2. CSS Reset

This page uses a custom CSS reset at the beginning of the stylesheet.

*, *::before, *::after {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}

3. box-sizing

Border Box

The declared width includes padding and border because the reset uses box-sizing: border-box.

box-sizing: border-box;

4. Media Elements

Images and other media can be made responsive with a common reset rule.

img, picture, svg, video, canvas {
    display: block;
    max-width: 100%;
}

5. Form Elements

Form elements can inherit the page font using font: inherit.

button, input, textarea, select {
    font: inherit;
}

6. Reset vs Normalize

CSS Reset

Removes or overrides many browser defaults to give you a clean starting point.


Normalize

Attempts to make useful browser defaults more consistent across browsers instead of removing everything.

7. Normalize Concept

The Normalize approach can be thought of as:


Browser A → Default styles

Browser B → Different defaults

Browser C → Different defaults


↓


More consistent baseline

8. Practical Modern Reset 

*,

    padding: 0;
    box-sizing: border-box;

9. Quick Summary

Browser defaults: Built-in styles provided by the browser.


CSS reset: Removes or overrides many defaults.


Normalize: Makes browser behavior more consistent while preserving useful defaults.


box-sizing: Makes width and height calculations easier to control.
